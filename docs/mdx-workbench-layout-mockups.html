Noch keine Boards

Lege ein neues Board an, hole bestehende aus einem Git-Repository oder importiere eine Board-Datei vom Dateisystem.

＋ Neues Board ⇣ Aus Git holen ⤒ Aus Datei importieren Konfiguration öffnen (Übersicht)
  1. 1Launcher ohne Seitenmenü: Die Boards-Seite zeigt nur Boards — Suche, Sortierung, Vorschau-Kacheln. Die Konfiguration erreicht man über „⚙ Konfiguration“ (Übersichts-Hub); das Menü links erscheint erst in den Arbeitsbereichen. „View“/„Edit“ sind Modus-Umschalter im geöffneten Board.
  2. 2Quelle Git: Boards aus dem Repository (lib/persistence/git) mit Sync-Status je Board („synchron“, „Update verfügbar“) und „⇣ Aus Git holen“ — ersetzt die separaten SaveLoad-/Configuration-Menüpunkte.
  3. 3„＋ Neues Board“ öffnet den Board-Editor (leer oder aus Vorlage).
  4. 4Quelle Dateisystem: Board-Datei (.json) per Drag & Drop oder Dateidialog importieren (heutiges „Upload file“, persistence/loader).

Noch keine Verbindung

Eine Verbindung ist der Zugang zu deinem Server (XMLA, REST, MQTT, …). Datenquellen bauen darauf auf und liefern die Daten für Board-Widgets.

＋ Verbindung anlegen Öffentlichen Demo-Server in der Workbench erkunden
  1. 1Ein Baum für beides: Verbindungen (mit Live-Status: verbunden/getrennt, Kataloge) und darunter ihre Datenquellen mit Verwendungshinweis; Anlage über „＋“ direkt im Baum.
  2. 2Detail rechts: Vorschau (Abfrage + Datenvorschau) oder Einstellungen der gewählten Quelle; Kopfzeile mit Status und Verwendungsnachweis („2 Boards · 5 Widgets“) vor dem Ändern/Löschen.
  3. 3Vertiefung: „⛶ Editor im Vollbild“ öffnet den Workbench-Editor (Screen „Daten-Editor“), „⌕ In Workbench erkunden“ die MDX Workbench mit dieser Verbindung.
  4. 4Anlage-Wege: „＋ Verbindung“/„＋ Datenquelle“ in der Topbar oder erkundend über die Workbench; der Leerzustand (Schalter „Erstnutzung“) führt Erstnutzer zur ersten Verbindung.
